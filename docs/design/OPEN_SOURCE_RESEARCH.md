### UX patterns
- Bottom sheet with detents (peek, then half, then full) over the map (seen in Google Maps / Apple Maps; Apple HIG sheet detents; Material 3 standard vs modal bottom sheets; NN/g 'Bottom Sheets' guidelines): Selecting a country on the map opens a non-modal peek strip in the page flow (not a popover stack). It shows the name, the number of published records matching the filters, coverage status and the last source check. 'Open evidence' opens a native modal <dialog> styled as a near-full-height sheet. Provide Expand/Collapse/Close buttons: dragging cannot be the only way (WCAG 2.5.7). Never stack one sheet on another. Long evidence scrolls inside the dialog. On desktop the same content renders as the side panel.
- Map / List segmented toggle, state kept in the URL (seen in Liveuamap (map plus feed tabs); Airbnb-style floating 'Show map / Show list' button; Carnegie and CrisisWatch map-plus-list): Make List the default view on mobile; this keeps the repo's 'readable index first' panel decision. Load D3 and geometry only when Map is first opened. Both views share one filter state and show identical counts, and the toggle writes ?view=map so permalinks reproduce it.
- Sticky, horizontally scrolling filter chips plus a 'Filters (n)' sheet (seen in Material 3 filter chips; e-commerce and news apps): Chips cover the common filters: 'Recent observation (<72h)', Planned/Announced, Needs review, Ended, plus the active region or issue. All other filters (year, city, outcome, country) go in a full filter sheet with a live result count and 'Clear all'. Active state is shown by text or a check icon, not colour alone. Targets are at least 24 px. Set scroll-padding-top equal to the sticky row height so focused rows are never hidden (WCAG 2.4.11).
- Bottom tab bar (3–5 labelled destinations) (seen in Material 3 navigation bar; Apple HIG tab bars): Possible tabs: Explore · Countries · Upcoming · Method (4). Be sceptical: on a single static page, a fixed bar costs about 56 px of a 640–700 px viewport and fights iOS Safari's own toolbar. Ship it only if testing beats a compact sticky top nav. If shipped, use env(safe-area-inset-bottom), body padding-bottom and scroll-padding-bottom.
- Key-events timeline strip with date-precision glyphs (seen in Guardian live-blog 'key events' list; Forensic Architecture TimeMap / Bellingcat timeline brush): Each event gets a horizontal strip of dated entries: onset, peaks, state actions, concessions, ending. Glyphs distinguish day, month and unknown precision, and unknown onset is drawn as an open-ended bracket rather than a fake date. A global weekly strip, if added, must be labelled 'published observations', never 'protest volume'.
- Freshness stamps: relative plus absolute, three kinds kept separate (seen in Liveuamap feed timestamps; news live pages' 'Updated' lines; Carnegie 'last updated' date): Show (1) 'Snapshot built' from build-info.json with the commit SHA, (2) 'Last source observation' per record, (3) 'Last editorial check'. Each is a <time datetime> with Intl.RelativeTimeFormat text ('14 hours ago') and the absolute UTC time visible on tap. Recompute every minute and on visibilitychange. Do not show a pulsing 'LIVE' badge; use 'Recent observation · 14 h ago' only inside the 72-hour window.
- Two-sided positions ledger (support vs against) instead of a stance bar (seen in Wikipedia Infobox civil conflict side1/side2; CCC stance coded against a named target): Two columns, 'For: <named demand/target>' and 'Against', plus 'Mixed / unclear'. Each lists attributed actors with source references. Reject proportional bars: one ministry against one union drawn as 50/50 implies a population split. If a cited poll exists, show it as a separate card with pollster, fieldwork dates, n and question wording.
- Faceted intensity row, no composite score (seen in CCC EstimateLow/High plus separate arrests and injuries; Carnegie peak size and duration; Mass Mobilization state-response list): Show separate facets: turnout range (low–high, who estimated it), duration (first-to-last report, in days), spread (number of referenced cities), disruption (strikes, blockades), and reported deaths/injuries/arrests by side, where 'not reported' never equals 0. No colour ramp ranks events, and the sort options never include 'severity'.
- State-response chips with actor and announced-vs-observed (seen in Mass Mobilization Project vocabulary (CC0); MMAD repressive actors; ACLED intervention vs excessive force distinction): One chip per response: accommodation / arrests / beatings / dispersal / ignore / killings / shootings, plus legal and administrative actions. Each chip names the actor (police, military, court, legislature), a date, an 'alleged' or 'officially stated' label, and source references. Conflicting tallies are shown side by side.
- Upcoming / announced actions list (seen in Fridays For Future action map calendar; Mobilize event listings): An 'Upcoming' tab shows organiser-announced actions at city and day precision only, with the announcement source and an 'announced ≠ occurred' label. Items move to 'Needs review' once the date passes. Never publish meeting points, times, routes or organiser personal details. Withhold announcements in high-repression contexts unless already widely reported.
- Coverage-honest choropleth and empty states (seen in CrisisWatch interactive map; Carnegie tracker map; repo's existing coverage-gap language): Map colours mean publication or review status, not intensity, and have pattern and text equivalents. A country with no record opens a sheet saying 'not reviewed' or 'searched, no published record', never 'no protests'.
- Share / permalink action (seen in News trackers' share buttons): A 'Copy link' button copies the current URL (Async Clipboard, Baseline 2024-06-11) and falls back to selecting text. Links reproduce filters and view; no tracking parameters.

### Recommendations
- Keep the D3 SVG Equal Earth map and reject MapLibre and PMTiles. Measured: MapLibre v6 is about 312 KB gzip of JS and CSS versus 92 KB for full D3. It offers only Mercator or globe projections, needs WebGL, and an OSM basemap brings ODbL attribution plus OSM's disputed-boundary choices.
- Cut mobile map weight. The map loads both public/world-countries.geo.json (437 KB / 150 KB gzip) and world-110m.topo.json (108 KB / 38 KB gzip). If the prepared GeoJSON only adds preprocessing, bake that into the TopoJSON and derive features with topojson.feature to save about 150 KB gzip. Optionally swap the full D3 bundle (92 KB gzip) for d3-geo/zoom/selection and their dependencies (42.7 KB gzip; the app calls only geoEqualEarth, geoPath, geoGraticule, zoom, zoomIdentity and select). Lazy-load all map assets on first Map view.
- Search: add no library yet. Fold diacritics with NFD normalize plus a regex strip, and AND-match tokens across the existing searchable fields. Adopt MiniSearch (MIT, 18.6 KB gzip) only when records pass about 500 or typo tolerance is requested. Reject Fuse.js and Pagefind for now.
