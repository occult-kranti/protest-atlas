# Protest Atlas design brief

Product: a public, source-led index of collective action, hosted as a static GitHub Pages site.

Primary job: explore published protest reporting on a country map and through country, issue, region, status and observed-date filters, then inspect attributed demands, positions, intensity, state response and original reporting. A separate local editor desk prepares draft decisions from unverified news leads.

Audience: curious readers and researchers who need to distinguish reported activity from uncertain or missing coverage.

Direction: an editorial field index with a functional D3 Equal Earth world map. Warm paper, deep ink, restrained ochre, serif story headings, compact sans-serif evidence labels and ruled rows. The map links country selection to a source-coverage panel and the record index. Color describes published reporting coverage, never intensity, popularity or a worldwide census. Country labels include territories rather than implying 249 sovereign states. The 249-entry directory remains the complete alternative to simplified map geometry.

Evidence: source links, source-check date, last source observation, verification notes, attribution, UTC dates and explicit unknowns. Release 3 contains 84 episodes across 81 countries, 118 city references and an initial search for every one of the 249 directory entries. Initial searches are separate from article-level source checks; 168 countries still have no published episode. Black shadows mean a sourced ended/suspended episode, never completed country research. Results name affected actors and label inference explicitly. English-source checks do not establish local-language coverage. The pilot is AI-assisted with no independent human editorial review; this disclosure belongs above the map and records. Discovery status is a dated static audit of a known artifact, never a live-health indicator or an event review time.

Constraints: static HTML/CSS/JavaScript with pinned local D3 7.9.0, TopoJSON Client 3.1.0 and world-atlas 2.0.2/Natural Earth assets. No frontend installation, mapping token, remote tiles or runtime CDN. Python validates and assembles an explicit publication allowlist; relative asset/JSON paths work under a GitHub Pages repository base path. No geolocation, analytics, identification of individual participants or invented metrics. Synthetic examples require an explicit switch, a clear watermark on map/list/detail, and exclusion from reported CSV export.

Invariants: zero records is a useful coverage-gap state; zero matching results is not evidence of no protests. Map, panel and index use the same filters; a country with reports outside the current filters differs from one with no published record. Observation presets use `last_observed_at`, never publication or discovery date. Ongoing statuses age against that observation and become Needs review at 72 hours. Future start dates remain Planned. Unknown onset stays unknown. Turnout, disruption, violence and state response are separate dimensions. Sources remain attached to claims. Filter permalinks reproduce the view; CSV retains source URLs, recorded-status uncertainty and formula escaping.

Responsive composition: desktop world map beside the linked country panel, followed by record index and explanatory reading key; tablet/mobile stack map and panel, wrap filters and keep country selection available. Map pan/zoom controls and the directory supplement pointer interaction. Map failure cannot block the index; small territories omitted by the 1:110m geometry remain selectable through the directory. Dialog uses native modal behavior, explicit close, initial heading focus, Escape and focus restoration.

Editor desk: import candidate JSON using a local file input, search provider metadata, read source links and enter evidence manually. Work stays in tab memory and exports only a local JSON review packet. Publisher country and GDELT seen time must never fill occurrence fields. “Ready for editor” requires source acknowledgement, nonfuture observed date, catalog country, claim summary and attribution; duplicate decisions need a published event ID. Draft readiness is not approval, enrollment of a human reviewer or automatic publication. No account, local storage or remote submission is part of this desk.
